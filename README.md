# chiron

chiron mounts any git repo as a **corpus** and helps you study it with your
agent. `/mount` clones the repo, builds an extraction adapter with you, and
renders layered notes you browse locally; each **register** (`v1/`, `v2/`, …)
is a retelling of the same material under its own translation requirements.
The notes that accumulate — key facts, schematics, the names things go by —
become a shared vocabulary for working on that material with an agent: you
learn to say what you mean in the corpus's own terms, and generated answers
stay inside them.
